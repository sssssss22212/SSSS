# 🎮 RP Телепорт Система - Полная документация

## 📖 Введение

**RP Телепорт Система** - это мощный плагин для RP серверов, который предоставляет полный функционал управления телепортацией игроков. Система включает в себя админ-панель, систему патчей, продвинутые настройки безопасности и логирование всех действий.

### ✨ Основные возможности

- 🌐 **Управление телепортами**: Создание, удаление, редактирование точек телепортации
- 👥 **Система ролей**: Гибкие настройки прав доступа для разных групп пользователей
- 🔧 **Система патчей**: Автоматическое обновление и применение изменений
- 📊 **Детальная статистика**: Отслеживание использования и популярности телепортов
- 🛡️ **Безопасность**: Проверка безопасности точек приземления
- 📋 **Логирование**: Полная история всех действий в системе
- 🎨 **Красивый интерфейс**: Современная веб-панель администратора

## 🚀 Установка и настройка

### Системные требования

- PHP 7.4 или выше
- Веб-сервер (Apache/Nginx)
- Права на запись в директорию проекта

### Пошаговая установка

1. **Скачайте файлы плагина** в директорию вашего веб-сервера
2. **Убедитесь, что все файлы присутствуют**:
   ```
   rp_teleport_plugin.php    # Основной файл плагина
   config_teleport.php       # Конфигурация
   admin_panel.php           # Админ-панель
   ```

3. **Настройте права доступа**:
   ```bash
   chmod 755 rp_teleport_plugin.php
   chmod 755 config_teleport.php
   chmod 755 admin_panel.php
   chmod 777 data/  # Директория будет создана автоматически
   ```

4. **Настройте конфигурацию** в файле `config_teleport.php`

## 💻 Использование API

### Создание телепорта

```php
// POST запрос к rp_teleport_plugin.php
$data = [
    'action' => 'create_teleport',
    'name' => 'Торговый центр',
    'x' => 100,
    'y' => 64,
    'z' => 100,
    'world' => 'default',
    'description' => 'Главный торговый центр сервера'
];
```

**Ответ**:
```json
{
    "success": true,
    "message": "Телепорт создан",
    "data": {
        "id": "tp_64f5a8b9c123456",
        "name": "Торговый центр",
        "coordinates": {"x": 100, "y": 64, "z": 100},
        "world": "default",
        "created_at": "2024-01-15 14:30:00"
    }
}
```

### Телепортация игрока

```php
$data = [
    'action' => 'teleport_player',
    'player_id' => 'player123',
    'teleport_id' => 'tp_64f5a8b9c123456'
];
```

**Ответ**:
```json
{
    "success": true,
    "message": "Успешная телепортация к 'Торговый центр'",
    "coordinates": {"x": 100, "y": 64, "z": 100},
    "world": "default"
}
```

### Получение списка телепортов

```php
$data = [
    'action' => 'get_teleports',
    'world' => 'default',           // Фильтр по миру (необязательно)
    'public_only' => true,          // Только публичные (необязательно)
    'search' => 'торговый'          // Поиск по названию (необязательно)
];
```

## 🔧 Система патчей

Система патчей позволяет автоматически обновлять конфигурацию и добавлять новые телепорты без прямого вмешательства в код.

### Структура патча

```json
{
    "version": "1.0.1",
    "description": "Добавление новых телепортов для ивента",
    "changes": [
        {
            "type": "add_teleport",
            "data": {
                "name": "Ивентовая зона",
                "x": 500,
                "y": 70,
                "z": 500,
                "world": "default",
                "description": "Специальная зона для проведения ивентов"
            }
        }
    ]
}
```

### Типы изменений в патчах

- **add_teleport**: Добавить новый телепорт
- **remove_teleport**: Удалить существующий телепорт
- **update_config**: Обновить конфигурацию

### Применение патча

```php
$data = [
    'action' => 'apply_patch',
    'patch_data' => json_encode($patch_structure)
];
```

## 🔄 Примеры использования

### Интеграция с существующим сайтом

```php
<?php
require_once 'rp_teleport_plugin.php';

// Инициализация плагина
$teleport = new RPTeleportPlugin();

// Получение списка телепортов для отображения на сайте
$teleports = $teleport->getTeleports(['public_only' => true]);

foreach ($teleports as $tp) {
    echo "<div class='teleport-card'>";
    echo "<h3>" . htmlspecialchars($tp['name']) . "</h3>";
    echo "<p>Координаты: {$tp['coordinates']['x']}, {$tp['coordinates']['y']}, {$tp['coordinates']['z']}</p>";
    echo "<p>Мир: {$tp['world']}</p>";
    echo "<p>{$tp['description']}</p>";
    echo "</div>";
}
?>
```

### AJAX запросы с JavaScript

```javascript
// Функция для телепортации через AJAX
async function teleportToLocation(teleportId) {
    try {
        const response = await fetch('rp_teleport_plugin.php', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/x-www-form-urlencoded',
            },
            body: `action=teleport_player&player_id=${playerId}&teleport_id=${teleportId}`
        });
        
        const result = await response.json();
        
        if (result.success) {
            showMessage('Телепортация успешна!', 'success');
        } else {
            showMessage(result.message, 'error');
        }
    } catch (error) {
        showMessage('Ошибка соединения', 'error');
    }
}
```

## 🎯 Расширенные возможности

### Кастомные хуки и события

Плагин поддерживает систему хуков для интеграции с другими модулями:

```php
// Пример добавления кастомной логики после телепортации
function onPlayerTeleport($player_id, $teleport_data) {
    // Ваша кастомная логика
    logCustomAction("Player {$player_id} teleported to {$teleport_data['name']}");
    
    // Отправка уведомления другим игрокам
    notifyOtherPlayers($player_id, $teleport_data);
}
```

### Интеграция с базой данных

Для больших серверов можно адаптировать систему для работы с MySQL:

```php
// Пример адаптации для MySQL
class MySQLTeleportPlugin extends RPTeleportPlugin {
    private $pdo;
    
    public function __construct($database_config) {
        $this->pdo = new PDO(
            "mysql:host={$database_config['host']};dbname={$database_config['db']}", 
            $database_config['user'], 
            $database_config['pass']
        );
    }
    
    public function loadTeleports() {
        $stmt = $this->pdo->query("SELECT * FROM teleports WHERE is_active = 1");
        return $stmt->fetchAll(PDO::FETCH_ASSOC);
    }
}
```

## 🆘 Решение проблем

### Частые ошибки и их решения

#### "Недостаточно прав"
**Проблема**: Пользователь не может выполнить действие
**Решение**: Проверьте роль пользователя в сессии и настройки прав в конфигурации

#### "Телепорт не найден"
**Проблема**: Система не может найти указанный телепорт
**Решение**: Проверьте корректность ID телепорта и существование файла данных

#### "Ошибка при создании директории data"
**Проблема**: Нет прав на создание директории
**Решение**: Установите права 777 на директорию проекта или создайте папку `data` вручную

### Отладка

Включите режим отладки для получения детальной информации:

```php
// В config_teleport.php
$logging_config['log_level'] = 'DEBUG';
ini_set('display_errors', 1);
error_reporting(E_ALL);
```

## 🔗 API Reference

### Все доступные действия

| Действие | Параметры | Описание |
|----------|-----------|----------|
| `create_teleport` | name, x, y, z, world, description | Создать телепорт |
| `delete_teleport` | teleport_id | Удалить телепорт |
| `teleport_player` | player_id, teleport_id | Телепортировать игрока |
| `get_teleports` | world, public_only, search | Получить список телепортов |
| `get_stats` | - | Получить статистику |
| `apply_patch` | patch_data | Применить патч |

### Структура ответов API

Все ответы возвращаются в формате JSON:

```json
{
    "success": true|false,
    "message": "Описание результата",
    "data": {} // Дополнительные данные при успехе
}
```
