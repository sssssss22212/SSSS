# SCP-096 Mask Plugin

Плагин для SCP: Secret Laboratory, который добавляет систему масок для SCP-096. Маски позволяют игрокам "маскировать" SCP-096, предотвращая его агрессию при взгляде на него.

## Особенности

### 🎭 Визуальные эффекты масок
- **Вытянутая форма** - маски имеют деформированный вид, отличающий их от обычных аптечек
- **Настраиваемые размеры** по осям X, Y, Z
- **Динамическая деформация** с анимацией растяжения
- **Свечение** с настраиваемым цветом и интенсивностью
- **Вращение** и **подпрыгивание** для привлечения внимания

### 🏢 Продвинутая система спавна
- **Конфигурируемые комнаты** с индивидуальными настройками
- **Шансы спавна** для каждой комнаты/зоны
- **Лимит масок** на комнату и карту
- **Конкретные позиции** спавна в комнатах
- **Условия спавна** (количество игроков, наличие SCP-096)
- **Респавн масок** в течение раунда

### ⚙️ Гибкие настройки активации
- **Серверные настройки** (рекомендуется) - игроки настраивают клавишу в меню
- **NoClip активация** - альтернативный способ

### 🛡️ Полная защита SCP-096
- Маскированный SCP-096 **не агрится** на игроков
- **Не добавляет цели** при взгляде
- **Не переходит в ярость**
- **Остается спокойным** при любых обстоятельствах

## Установка

1. Поместите плагин в папку `EXILED/Plugins/`
2. Перезапустите сервер
3. Настройте конфигурацию в `EXILED/Configs/(порт)-config.yml`

## Конфигурация

### Основные настройки
```yaml
scp096_mask:
  is_enabled: true
  debug: false
  auto_spawn_enabled: true
  masks_to_spawn: 5
  mask_equip_time: 8
  interaction_distance: 3
  require_mask_in_hand: true
```

### Визуальные настройки
```yaml
  visual_settings:
    scale_x: 1.5          # Растяжение по X (ширина)
    scale_y: 0.8          # Сжатие по Y (высота)
    scale_z: 1.2          # Растяжение по Z (глубина)
    enable_glow: true
    enable_rotation: true
    enable_bobbing: true
    enable_deformation: true  # Динамическая деформация
    deformation_intensity: 0.2
    deformation_speed: 1.5
```

### Настройки спавна по комнатам
```yaml
  room_spawn_configs:
  - room_type: Hcz096
    spawn_chance: 80
    max_masks_in_room: 2
    min_players_required: 3
    spawn_only_with_scp096: true
    spawn_positions:
    - x: 0
      y: 1.2
      z: 0
    - x: 3
      y: 1.2
      z: 3
    is_enabled: true
    priority: 5
```

### Дополнительные настройки
```yaml
  advanced_spawn:
    use_advanced_room_spawn: true
    only_when_scp096_present: true
    min_players_for_spawn: 5
    max_masks_on_map: 8
    enable_respawn: false
    respawn_interval: 300
    respawn_chance: 30
```

## Команды

### Для игроков
- `usemask` / `mask` - Использовать маску SCP-096

### Для администраторов
- `mask096 spawn [количество]` - Заспавнить маски
- `mask096 info` - Основная информация
- `mask096 stats` - Детальная статистика
- `mask096 give <userid> [x] [y] [z]` - Создать маску в позиции
- `mask096 giveinv <userid>` - Выдать маску в инвентарь
- `mask096 remove <userid>` - Снять маску с SCP-096
- `mask096 list` - Список замаскированных SCP-096
- `mask096 clear` - Удалить все маски
- `mask096 reload` - Перезагрузить конфигурацию
- `mask096 debug [on/off]` - Переключить отладку

## Права доступа

- `mask096.admin` - Полный доступ к командам администратора
- `mask096.info` - Доступ к команде информации

## Как работает

1. **Спавн масок** - В начале раунда на карте появляются маски-аптечки с особым внешним видом
2. **Подбор** - Игроки подбирают маски как обычные предметы
3. **Одевание** - Подойдя к SCP-096 с маской в руке, игрок может надеть её (процесс занимает время)
4. **Эффект** - Замаскированный SCP-096 перестает агриться и не реагирует на взгляды
