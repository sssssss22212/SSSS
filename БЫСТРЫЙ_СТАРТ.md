# 🚀 Быстрый старт - Умный бот для Minecraft

## 📱 Запуск на телефоне (Termux)

### Шаг 1: Установка Termux
1. Скачайте Termux из F-Droid или Google Play
2. Откройте Termux

### Шаг 2: Установка Node.js
```bash
pkg update
pkg upgrade
pkg install nodejs git
```

### Шаг 3: Скачивание бота
```bash
cd ~
git clone [ссылка на репозиторий]
cd minecraft-intelligent-bot
```

Или если у вас файлы на телефоне:
```bash
cd /storage/emulated/0/Download/minecraft-intelligent-bot
```

### Шаг 4: Установка зависимостей
```bash
npm install
```

### Шаг 5: Запуск бота
```bash
npm start
```

или

```bash
./start.sh
```

## 💻 Запуск на компьютере

### Windows

1. Скачайте и установите Node.js: https://nodejs.org/
2. Распакуйте файлы бота в папку
3. Откройте папку с ботом
4. Дважды кликните на `start.bat`

Или через командную строку:
```cmd
npm install
npm start
```

### Linux / Mac

1. Установите Node.js
2. Откройте терминал в папке с ботом
3. Выполните:
```bash
chmod +x start.sh
./start.sh
```

Или:
```bash
npm install
npm start
```

## ⚙️ Настройка сервера

Откройте файл `minecraft_bot.js` и найдите:

```javascript
const BOT_CONFIG = {
    host: 'n1.netronyx.pro',  // <- Измените на ваш сервер
    port: 4007,                 // <- Измените порт
    username: 'SmartBot_' + Math.floor(Math.random() * 1000),
    version: '1.21.8',
    auth: 'offline'
};
```

Или используйте файл `config.json` для настройки.

## 🎮 Первые шаги после подключения

После того как бот подключился к серверу, напишите в чат:

### 1. Базовое управление
```
помощь          - список команд
статус          - проверить состояние
где             - узнать координаты
ко мне          - вызвать к себе
следуй          - следовать за вами
```

### 2. Дать боту снаряжение
```
drop            - бот выбросит все что у него есть
(бросьте ему кирку, топор, броню, еду)
экипируй        - бот автоматически наденет броню и возьмет оружие
```

### 3. Начать работу
```
копай камень    - добыть камень
руби дерево     - срубить деревья
строй дом       - построить дом
атакуй мобы     - убить враждебных мобов
```

### 4. Автономный режим
```
авто            - включить автономный режим
                  (бот сам будет собирать ресурсы, 
                   защищаться, есть еду)
```

## ⚠️ Решение проблем

### "Cannot find module 'mineflayer'"
Установите зависимости:
```bash
npm install
```

### Бот не подключается
1. Проверьте правильность адреса сервера
2. Убедитесь что сервер работает
3. Проверьте версию Minecraft (должна быть 1.21.8 или близкая)

### Бот не отвечает на команды
1. Пишите команды в игровой чат, не в консоль
2. Проверьте что вы на том же сервере
3. Попробуйте команду `помощь`

### Ошибки на телефоне
Если мало памяти:
```bash
pkg clean
npm cache clean --force
```

### Бот вылетает
Перезапустите:
```bash
npm start
```

Бот автоматически переподключится при потере соединения.

## 💡 Советы

1. **Дайте боту инструменты** - он будет работать эффективнее
2. **Используйте автономный режим** - бот сам будет принимать решения
3. **Бот учится** - чем дольше работает, тем умнее становится
4. **Бросайте боту еду** - он будет автоматически есть при голоде
5. **Бот защищается сам** - отступит при низком здоровье
