ℹ️ О проекте

🎯 Что это?

Это демо версия игры "Мафия 2.0" для статических хостингов (как Infinity).

⚡ Как работает?

Настоящая версия требует Node.js сервер для мультиплеера.

Эта версия использует Firebase для имитации мультиплеера.

🔧 Возможности Firebase версии:

  • ✅ Красивый интерфейс
  • ✅ Анимации и эффекты
  • ✅ Регистрация игроков
  • ✅ Создание комнат
  • ⚠️ Ограниченный мультиплеер
  • ⚠️ Упрощенная игровая логика

🚀 Для полной версии нужно:

  • 🖥️ VPS сервер с Node.js
  • 🌐 Или Heroku/Railway/Vercel
  • 💰 Или локальный сервер

💡 Рекомендации для хостинга:

Бесплатные варианты:

  • 🔷 Railway.app (500 часов бесплатно)
  • 🔷 Render.com (750 часов бесплатно)
  • 🔷 Heroku (ограниченно)
