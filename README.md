# SCP Roleplay Plugin для Exiled

Полнофункциональный плагин для создания ролевого сервера в SCP: Secret Laboratory с использованием фреймворка Exiled.

## 🎭 Основные возможности

### Система ролей
- **8 предустановленных ролей**: от D-класса до администратора объекта
- **Система разрешений**: каждая роль имеет свои права и возможности  
- **Автоматическое назначение**: роли могут назначаться автоматически при спавне
- **Управление ролями**: команды для назначения и снятия ролей

### Денежная система
- **Банковские аккаунты**: автоматическое создание для новых игроков
- **Переводы между игроками**: безопасная система переводов
- **История транзакций**: подробная история всех операций
- **Административные команды**: выдача, снятие и установка баланса
- **Топ игроков**: рейтинг самых богатых игроков

### Медицинская система
- **8 типов травм**: от синяков до критических повреждений
- **4 уровня серьезности**: легкие, умеренные, серьезные и критические
- **Медицинские осмотры**: детальный анализ состояния пациента
- **Система лечения**: только квалифицированные "врачи" могут лечить серьезные травмы
- **Группы крови**: случайное назначение при создании профиля
- **Автоматическое восстановление**: постепенное лечение при отсутствии серьезных травм

### Продвинутая система чата
- **IC/OOC каналы**: разделение ролевого и неролевого общения
- **Локальный чат**: сообщения слышны только в определенном радиусе
- **Ролевые команды**: `/me`, `/do` для описания действий и окружения
- **Радиосвязь**: связь между совместимыми ролями
- **Шепот и крик**: различные уровни громкости сообщений
- **Система близости**: реалистичная передача сообщений

## 📦 Установка

### Требования
- SCP: Secret Laboratory сервер
- [Exiled](https://github.com/Exiled-Team/EXILED) Framework (версия 8.0+)
- .NET Framework 4.8

### Инструкция по установке

1. **Скачайте Exiled** и установите его на ваш сервер SCP:SL
2. **Скомпилируйте плагин**:
   ```bash
   dotnet build SCPRoleplayPlugin.csproj --configuration Release
   ```
3. **Скопируйте файлы**:
   - `SCPRoleplayPlugin.dll` → `%AppData%\EXILED\Plugins\`
   - Зависимости Exiled должны быть в папке `Dependencies\`

4. **Перезапустите сервер**

### Структура файлов
```
EXILED/
├── Plugins/
│   └── SCPRoleplayPlugin.dll
├── Configs/
│   └── SCPRoleplay/
│       └── money.json (создается автоматически)
└── Dependencies/
    ├── Exiled.API.dll
    ├── Exiled.Events.dll
    └── ... (другие зависимости Exiled)
```

## ⚙️ Конфигурация

Основные настройки плагина (в файле конфигурации Exiled):

```yaml
scp_roleplay_plugin:
  is_enabled: true
  debug: false
  role_command_prefix: "!"
  restrict_roles_to_groups: true
  allowed_role_groups:
  - "admin"
  - "moderator" 
  - "gamemaster"
  auto_assign_roles: false
  max_roles_per_player: 3
  enable_money_system: true
  starting_money: 1000
  enable_rp_channels: true
  ooc_prefix: "[OOC]"
  ic_prefix: "[IC]"
  local_chat_radius: 5.0
  enable_medical_system: true
  health_regen_time: 30.0
```

## 🎮 Команды

### Система ролей
```
!role                           - справка по ролям
!role list                      - список всех ролей
!role my                        - ваши роли
!role info <id>                 - информация о роли
!role assign <игрок> <роль>     - назначить роль (админ)
!role remove <игрок> <роль>     - снять роль (админ)
```

### Денежная система
```
!money                          - справка по деньгам
!money balance [игрок]          - баланс игрока
!money transfer <игрок> <сумма> - перевести деньги
!money top                      - топ богатых игроков
!money history                  - история транзакций
!money give <игрок> <сумма>     - дать деньги (админ)
!money take <игрок> <сумма>     - забрать деньги (админ)
!money set <игрок> <сумма>      - установить баланс (админ)
```

### Медицинская система
```
!medical                        - справка по медицине
!medical status [игрок]         - состояние здоровья
!medical checkup <игрок>        - провести осмотр
!medical heal <игрок> <номер>   - лечить травму
!medical injure <игрок> <тип> <серьезность> - добавить травму (админ)
```

### Система чата
```
/me <действие>                  - описание ваших действий
/do <описание>                  - описание окружения
/local <сообщение>              - локальный чат
/whisper <сообщение>            - шепот
/shout <сообщение>              - крик
/radio <сообщение>              - радиосвязь
((сообщение)) или [OOC]         - чат вне роли
```

### Общие команды
```
!rphelp                         - полная справка по серверу
```

## 🏥 Медицинская система

### Типы травм
- **Bruise** (Синяк) - легкие повреждения
- **Cut** (Порез) - небольшие раны
- **Fracture** (Перелом) - переломы костей (влияет на движение)
- **Burn** (Ожог) - термические повреждения
- **Bleeding** (Кровотечение) - потеря крови
- **Poisoning** (Отравление) - интоксикация
- **Infection** (Инфекция) - заражение
- **Other** (Прочее) - другие виды травм

### Уровни серьезности
- **Minor** (Легкая) - может лечить любой
- **Moderate** (Умеренная) - требует базовых медицинских навыков
- **Serious** (Серьезная) - требует продвинутых навыков
- **Critical** (Критическая) - требует экспертных навыков

## 🎭 Доступные роли

### Научный персонал
- **Научный сотрудник** - базовый исследователь
- **Старший научный сотрудник** - опытный исследователь с расширенными правами

### Служба безопасности
- **Кадет охраны** - новичок в службе безопасности
- **Офицер охраны** - опытный сотрудник безопасности

### D-класс персонал
- **D-класс заключенный** - подопытный субъект

### Специальные роли
- **Оперативник МОГ** - боец мобильной оперативной группы
- **Оперативник ХИ** - агент Хаоса Инсурженси
- **Администратор объекта** - руководитель с полными правами

## 🔧 Разрешения


### API для разработчиков

Плагин предоставляет простое API для взаимодействия с системами:

```csharp
// Работа с ролями
Plugin.Instance.RoleSystem.AssignRole(player, "scientist_researcher");
Plugin.Instance.RoleSystem.HasPermission(player, "access_research");

// Работа с деньгами
Plugin.Instance.MoneySystem.AddMoney(player, 100, "Награда");
Plugin.Instance.MoneySystem.GetBalance(player);

// Медицинская система
Plugin.Instance.MedicalSystem.AddInjury(player, InjuryType.Cut, InjurySeverity.Minor);
Plugin.Instance.MedicalSystem.PerformCheckup(patient, doctor);
```

## 🐛 Устранение неполадок

### Распространенные проблемы

1. **Плагин не загружается**
   - Проверьте версию Exiled (требуется 8.0+)
   - Убедитесь, что все зависимости на месте
   - Проверьте логи сервера

2. **Команды не работают**
   - Убедитесь, что плагин включен в конфигурации
   - Проверьте права доступа
   - Убедитесь в правильности синтаксиса команд

3. **Данные не сохраняются**
   - Проверьте права записи в папку конфигураций
   - Убедитесь, что папка `SCPRoleplay` создана

### Логирование

Включите отладочный режим в конфигурации для подробного логирования:
```yaml
debug: true
```
