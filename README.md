# 🤖 Умный Бот для Minecraft 1.21.8

Полнофункциональный автономный бот с обучением, строительством, добычей ресурсов, боем и расширенной стратегией.

## ✨ Возможности

### 🎮 Базовые функции
- ✅ Подключение к серверу Minecraft 1.21.8
- ✅ Автоматическое движение и навигация
- ✅ Ходьба, бег, прыжки, плавание
- ✅ Избегание опасностей (лава, падения, вода)

### ⛏️ Добыча ресурсов
- ✅ Добыча всех типов блоков и руд
- ✅ Автоматический выбор подходящего инструмента
- ✅ Умное распознавание русских названий (камень, железо, алмаз и т.д.)
- ✅ Добыча дерева, камня, железа, угля, алмазов
- ✅ Запоминание локаций ресурсов

### 🏗️ Строительство

- ✅ Построй стену - строит защитную стену
- ✅ Построй башню - строит высокую башню
- ✅ Построй мост - строит мост через препятствия
- ✅ Построй укрытие - быстрое укрытие 3x3
- ✅ Построй платформу - большая платформа 7x7
- ✅ Автоматический выбор материалов для строительства

### ⚔️ Боевая система
- ✅ Атака враждебных мобов (зомби, скелеты, пауки, криперы и др.)
- ✅ Автоматическая экипировка лучшего оружия
- ✅ Защита и отступление при низком здоровье
- ✅ Умная стратегия боя с критическими ударами
- ✅ Автоматическое использование щита

### 🎒 Управление инвентарем
- ✅ Автоматическая экипировка брони (алмазная > железная > кольчужная > золотая > кожаная)

- ✅ Команда "drop" для сброса всех предметов или конкретного
- ✅ Автоматическая организация инвентаря
- ✅ Подбор выброшенных предметов и автоэкипировка

- ✅ Автоматический крафт верстака

- ✅ Запоминание рецептов

### 📡 Команды в чате

#### Движение
- `иди [координаты/игрок]` - идти к точке или игроку
- `стой` - остановиться
- `следуй` / `иди за мной` - следовать за игроком
- `ко мне` - подойти к игроку

#### Добыча
- `копай [тип]` - добывать ресурс (камень, железо, уголь, алмаз и т.д.)
- `руби дерево` - рубить деревья
- `ломай [блок]` - сломать определенный блок

#### Строительство
- `строй дом` - построить дом
- `строй стену` - построить стену
- `строй башню` - построить башню
- `строй мост` - построить мост
- `строй укрытие` - построить укрытие
- `строй платформу` - построить платформу
- `ставь [блок]` - поставить блок

#### Бой
- `атакуй [цель/мобы]` - атаковать
- `убей мобы` - убить враждебных мобов
- `защищайся` - режим защиты

#### Инвентарь
- `инвентарь` - показать содержимое инвентаря
- `drop` / `drop все` - выбросить все предметы
- `drop [предмет]` - выбросить конкретный предмет
- `экипируй` - надеть лучшую броню и взять оружие

#### Крафт и еда
- `крафт [предмет]` - скрафтить предмет
- `ешь` - поесть

#### Информация
- `статус` - показать статус бота
- `где` - показать координаты
- `помощь` - список команд
- `статистика` - показать статистику обучения

#### Режимы
- `авто` - переключить автономный режим
- `охраняй` - охранять текущую позицию
- `исследуй` - исследовать окрестности

## 📦 Установка

### На компьютере (Windows/Linux/Mac)

1. Установите Node.js (версия 16 или выше):
   - Скачайте с https://nodejs.org/

2. Клонируйте или скачайте этот проект

3. Установите зависимости:
```bash
npm install
```

4. Запустите бота:
```bash
npm start
```

### На телефоне через Termux (Android)

1. Установите Termux из F-Droid или Google Play

2. Откройте Termux и установите необходимые пакеты:
```bash
pkg update && pkg upgrade
pkg install nodejs git
```

3. Скачайте проект:
```bash
git clone <ваш-репозиторий>
cd minecraft-intelligent-bot
```

4. Установите зависимости:
```bash
npm install
```

5. Запустите бота:
```bash
npm start
```

### Через Proot Ubuntu в Termux

1. Установите Proot Ubuntu:
```bash
pkg install proot-distro
proot-distro install ubuntu
proot-distro login ubuntu
```

2. В Ubuntu установите Node.js:
```bash
apt update
apt install nodejs npm git
```

3. Клонируйте и запустите:
```bash
git clone <ваш-репозиторий>
cd minecraft-intelligent-bot
npm install
npm start
```

```javascript

    host: 'n1.netronyx.pro',  // Адрес сервера
```

## 🐛 Решение проблем

### Бот не подключается
- Проверьте адрес и порт сервера
- Убедитесь что сервер работает в offline режиме
- Проверьте версию Minecraft

### Ошибки при установке
```bash
# Очистите кеш npm
npm cache clean --force
# Удалите node_modules и переустановите
rm -rf node_modules
npm install
```

### Бот не выполняет команды
- Пишите команды в чат сервера (не в консоль)
- Команды должны быть на русском или английском
- Проверьте список команд через `помощь`
