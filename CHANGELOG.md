# Журнал изменений - SCP-096 Mask Plugin

## Версия 1.2.0 - Финальная версия

### ✨ Новые возможности
- **Визуальное отличие масок**: Маски теперь растянуты (X: 1.5x, Y: 0.8x, Z: 1.2x) и отличаются от обычных аптечек

- **Продвинутая система спавна**: Конфигурируемые позиции в конкретных комнатах с индивидуальными настройками
- **Спавн через пикап**: Маски создаются напрямую через Pickup.CreateAndSpawn() для лучшей производительности
- **API для разработчиков**: Полноценный API с событиями для интеграции с другими плагинами
- **Система событий**: Кастомные события для подбора, одевания и снятия масок
- **Утилиты**: Набор вспомогательных функций для работы с масками
- **Константы**: Централизованные константы для всех значений плагина

### 🚀 Установка
1. Скомпилируйте проект с .NET 6.0
2. Поместите DLL в папку EXILED/Plugins/
3. Настройте конфигурацию в config.yml
4. Перезапустите сервер

### ⚡ Быстрый старт
```yaml
scp096_mask:
  is_enabled: true
  auto_spawn_enabled: true
  masks_to_spawn: 5
  visual_settings:
    scale_x: 1.5    # Растяжение маски
    scale_y: 0.8    # Сжатие маски
    scale_z: 1.2    # Увеличение маски
```

### 🔗 API Использование
```csharp
// Проверить, есть ли у игрока маска
bool hasMask = MaskAPI.HasMask(player);

// Выдать маску игроку
bool success = MaskAPI.GiveMask(player);

// Создать маску в позиции
Pickup mask = MaskAPI.SpawnMask(position);

// Подписаться на события
MaskAPI.MaskEquipped += OnMaskEquipped;
```
