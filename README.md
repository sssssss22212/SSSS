# 🎭 SCP-035 "Одержимая Маска" - Плагин для SCP Secret Laboratory

## 📖 Описание

Этот плагин добавляет в игру **SCP-035 "Одержимая Маска"** - кастомную роль с уникальными способностями контроля других игроков. Плагин использует **HSM (HintServiceMeow)** для красивых подсказок и предоставляет полную систему конфигурации.

### 🌟 Основные возможности:
- ✅ **Кастомная роль SCP-035** с уникальными способностями
- ✅ **Механика контроля игроков** (Possession)
- ✅ **Система коррозии** для баланса
- ✅ **Вселение после смерти** в ближайших игроков
- ✅ **HSM подсказки** для красивого интерфейса
- ✅ **Полная настройка** всех параметров
- ✅ **Команды администратора** для управления
- ✅ **Многоязычная поддержка** (русский/английский)

---

## 🚀 Установка

1. **Скачайте Exiled** последней версии
2. **Установите HintServiceMeow** плагин
3. **Поместите файлы плагина** в папку `plugins`
4. **Перезапустите сервер**

### 📁 Структура файлов:
```
plugins/
├── SCP035Plugin.dll
├── HintServiceMeow.dll
└── dependencies/
    └── (зависимости Exiled)
```

## 🎮 Как играть за SCP-035

### 🎯 Цель
Выжить и посеять хаос в комплексе, контролируя других игроков

### 🎭 Способности

#### 1. **Контроль игроков (Possession)**
- **Активация**: Нажмите ПКМ фонариком рядом с целью
- **Дальность**: 5 метров (настраивается)
- **Длительность**: 15 секунд (настраивается)
- **Кулдаун**: 20 секунд (настраивается)

#### 2. **Открытие дверей**
- SCP-035 может открывать двери без карт доступа
- Использует психические способности

#### 3. **Регенерация**
- Может лечиться медикаментами (с пониженной эффективностью)
- Медкит восстанавливает 60 HP вместо 100

#### 4. **Вселение после смерти**
- При смерти может вселиться в ближайшего игрока
- Шанс успеха: 40% (настраивается)
- Дальность: 10 метров (настраивается)

### ⚠️ Ограничения

#### 🧪 **Коррозия**
- SCP-035 медленно получает урон от коррозии
- Урон: 3 HP каждые 8 секунд (настраивается)
- Можно замедлить лечением

#### 🛡️ **Модификаторы урона**
- Пулевые ранения: 80% урона
- Взрывы: 120% урона
- Тесла: 150% урона
- Боеголовка: 200% урона

## ⚙️ Конфигурация

### 📊 Основные настройки

```yaml
# Включен ли плагин SCP-035
is_enabled: true

# Режим отладки
debug: false

# Автоматический спавн SCP-035
enable_s_c_p035_spawn: true

# Минимальное количество игроков для спавна
min_players_for_spawn: 5

# Шанс спавна (% от игроков)
s_c_p035_spawn_chance: 15

# Максимальное количество SCP-035
max_s_c_p035_count: 2
```

### 🎭 Характеристики SCP-035

```yaml
# Здоровье SCP-035
s_c_p035_health: 150

- Medkit
- KeycardJanitor

# Может открывать двери
s_c_p035_can_open_doors: true

s_c_p035_healing_efficiency: 0.6
```

### 🧠 Настройки контроля


### 🧪 Настройки коррозии

## 🐛 Устранение проблем

### ❌ Частые проблемы

#### **Плагин не загружается**
1. Проверьте версию Exiled
2. Убедитесь, что установлен HintServiceMeow
3. Проверьте логи сервера

#### **Подсказки не отображаются**
1. Проверьте настройки HSM
2. Убедитесь в правильности конфигурации
3. Проверьте позиции подсказок

#### **Контроль не работает**
1. Проверьте дальность до цели
2. Убедитесь, что кулдаун прошёл
3. Проверьте шансы контроля для роли

### 📊 Отладка

Включите режим отладки в конфигурации:
```yaml
debug: true
```

Это добавит подробные логи в консоль сервера.
