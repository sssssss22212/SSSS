# SCP-096 Mask Plugin

Плагин для SCP Secret Laboratory, который добавляет маски SCP-096. Маски представляют собой аптечки, которые спавнятся в комнатах. Игроки могут надевать маски на SCP-096, чтобы он не агрился при взгляде.

## Функции

- 🎭 **Спавн масок**: Аптечки-маски автоматически спавнятся в комнатах по настраиваемым зонам
- 🔧 **Взаимодействие**: Настраиваемые клавиши через server-specific settings для взаимодействия с SCP-096
- ⏱️ **Таскбар**: Прогресс-бар при одевании маски на SCP-096
- 🚫 **Отключение агра**: SCP-096 с маской не агрится при взгляде на него
- 💬 **HSM хинты**: Красивые хинты через HintServiceMeow
- ⚙️ **Настройки**: Полностью настраиваемый конфиг

## Установка

1. Скомпилируйте плагин
2. Поместите `.dll` файл в папку `EXILED/Plugins`
3. Перезапустите сервер

## Зависимости

- **Exiled** версии 9.6.1 или выше
- **HintServiceMeow** для отображения хинтов
- **Harmony** для патчей SCP-096

## Использование

### Для игроков

1. Найдите аптечку-маску в комнатах
2. Подойдите к SCP-096 на расстояние взаимодействия (по умолчанию 3м)
3. Нажмите настроенную клавишу взаимодействия
4. Дождитесь завершения процесса одевания (по умолчанию 5 сек)

### Настройка клавиш

Зайдите в настройки игры → Server-Specific Settings → найдите секцию "Scp096Mask" → настройте клавишу взаимодействия.

### Команды администратора

Все команды требуют права `mask096.admin`:

- `mask096 spawn` - заспавнить маски заново
- `mask096 info` - информация о текущих масках
- `mask096 give <userid>` - выдать маску игроку
- `mask096 remove <userid>` - снять маску с SCP-096
- `mask096 list` - список замаскированных SCP-096

## Конфигурация

### Основные настройки

```yaml
# Включен ли плагин
is_enabled: true

# Режим отладки
debug: false

# Тип активации (ServerSpecificSettings или NoClip)
activation_type: ServerSpecificSettings

# Автоматический спавн масок
auto_spawn_enabled: true

# Количество масок для спавна
masks_to_spawn: 8

# Время одевания маски (секунды)
mask_equip_time: 5.0

# Дистанция взаимодействия с SCP-096 (метры)
interaction_distance: 3.0
```

### Спавн по зонам

```yaml
spawn_weights:
  LightContainment: 35.0
  HeavyContainment: 45.0
  Entrance: 15.0
  Surface: 5.0
```

### Настройки хинтов

```yaml
hint_settings:
  text_size: 20
  x_position: 0
  y_position: 50
```

### Сообщения

Все сообщения настраиваются в секции `messages`:

- `mask_picked_up` - при подборе маски
- `mask_equipping` - при одевании маски
- `mask_equipped` - при успешном одевании
- `too_far_away` - когда игрок далеко от SCP-096
- `no_mask` - когда у игрока нет маски
- `already_masked` - когда на SCP-096 уже есть маска

### Server-Specific Settings

```yaml
setting_header_label: "Scp096Mask"
keybind_id: 300
keybind_label: "Взаимодействие с SCP-096"
keybind_hint: "Позволяет надеть маску на SCP-096"
```

## Как работает

1. **Спавн масок**: При начале раунда в случайных комнатах спавнятся аптечки-маски
2. **Подбор**: Игроки подбирают аптечки как обычно
3. **Взаимодействие**: Подойдя к SCP-096 и нажав клавишу, начинается процесс одевания
4. **Прогресс**: Показывается таскбар с прогрессом одевания маски
5. **Блокировка агра**: Harmony патчи блокируют агр SCP-096 с маской
