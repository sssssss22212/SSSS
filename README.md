# 🕵️ МАФИЯ 2.0 - Мультиплеерная онлайн игра

Полнофункциональная мультиплеерная игра "Мафия" с красивым интерфейсом, множеством ролей, системой достижений и настоящим веб-сокет мультиплеером.

## ✨ Основные возможности

### 🎮 Игровой процесс
- **14 уникальных ролей** с различными способностями
- **Смена дня и ночи** с красивыми анимациями
- **Голосование и ночные действия** с таймерами
- **Чат в реальном времени** для общения
- **Автоматическое определение победителей**

### 🌐 Мультиплеер
- **Настоящий WebSocket сервер** для реального времени
- **Создание и присоединение к комнатам** по коду
- **До 16 игроков** в одной игре
- **Система готовности** перед началом игры
- **Автоматическое переподключение**

### 👤 Система пользователей
- **Регистрация и авторизация** с сохранением данных
- **Система уровней и опыта**
- **Подробная статистика** игр и побед
- **Достижения** за различные действия
- **Рейтинг лучших игроков**

### 🛒 Магазин и кастомизация
- **Различные аватары** (розовый, золотой, радужный)
- **Темы оформления** (светлая/темная)
- **VIP статус** с дополнительными возможностями
- **Улучшенные анимации**
- **Система монет** для покупок

### 🏆 Турниры и соревнования
- **Еженедельные турниры**
- **Чемпионаты месяца**
- **Быстрые турниры**
- **Турнирная сетка** с отображением матчей

## 🚀 Запуск игры

### Установка зависимостей
```bash
npm install
```

### Запуск сервера
```bash
npm start
```

Или для разработки:
```bash
npm run dev
```

### Открытие игры
Откройте браузер и перейдите на `http://localhost:3000`

## 📁 Структура проекта

```
/workspace/
├── server.js          # Node.js сервер с Socket.io
├── index.html         # Главный HTML файл с интерфейсом
├── client.js          # JavaScript клиент
├── package.json       # Зависимости проекта
├── data/              # Папка для JSON файлов с данными
│   ├── users.json     # База пользователей
│   ├── rooms.json     # Активные комнаты
│   └── stats.json     # Общая статистика
└── README.md          # Этот файл
```

## 💾 Сохранение данных

Все данные автоматически сохраняются в JSON файлы:
- **users.json** - профили пользователей, статистика, инвентарь
- **rooms.json** - активные игровые комнаты
- **stats.json** - общая статистика сервера

Автосохранение происходит каждые 5 минут и при важных событиях.

## 🔧 Технические особенности

### Backend
- **Node.js** с Express
- **Socket.io** для WebSocket соединений
- **JSON файлы** для базы данных
- **Автоматическое сохранение** данных
- **API эндпоинты** для статистики

### Frontend
- **Vanilla JavaScript** без фреймворков
- **CSS Grid** и Flexbox для макета
- **CSS анимации** и переходы
- **Responsive дизайн**
- **WebSocket клиент**

### Безопасность
- Валидация всех пользовательских данных
- Защита от SQL инъекций (не используется SQL)
- Ограничения на длину сообщений
- Проверка прав доступа

## 🐛 Отладка

Для отладки откройте консоль браузера (F12) - там отображаются:
- Подключения к серверу
- Игровые события
- Ошибки соединения
- Отправка сообщений

## 🚀 Развертывание

Для развертывания на сервере:

1. Установите Node.js на сервере
2. Скопируйте файлы проекта
3. Установите зависимости: `npm install`
4. Запустите: `npm start`
5. Настройте порт через переменную окружения `PORT`
