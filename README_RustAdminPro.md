# RustAdminPro - Профессиональная админ панель для Rust

## Описание
RustAdminPro - это мощный плагин для Rust сервера на базе Oxide/uMod, который предоставляет администраторам удобную панель управления с красивым интерфейсом.

## Возможности
- 🛡️ **Админ панель** - Полнофункциональная панель управления
- 👥 **Управление игроками** - Кик, бан, мут, телепорт игроков
- 🏪 **Магазин** - Встроенная система магазина с валютой
- 📦 **Система китов** - Настраиваемые наборы предметов
- 🌍 **Телепорт** - Быстрый телепорт по локациям
- 💰 **Система валюты** - Управление балансом игроков
- ⚠️ **Система предупреждений** - Выдача варнов игрокам
- 💬 **Фильтр чата** - Система мута игроков
- 🎨 **Красивый UI** - Современный интерфейс

## Установка

1. Поместите файл `Panel.cs` в папку `oxide/plugins/` вашего сервера
2. Поместите файл `RustAdminPro.json` в папку `oxide/config/` (опционально)
3. Поместите файл `RustAdminPro_data.json` в папку `oxide/data/` (опционально)
4. Перезапустите сервер или выполните команду `o.reload RustAdminPro`

## Права доступа

Плагин использует следующие права доступа:
- `rustadminpro.admin` - Полный доступ к админ панели
- `rustadminpro.moderator` - Доступ к модераторским функциям
- `rustadminpro.vip` - VIP привилегии

### Выдача прав:
```
o.grant user <SteamID> rustadminpro.admin
o.grant group admin rustadminpro.admin
```

## Команды

### Чат команды:
- `/admin` - Открыть админ панель
- `/tp <игрок/координаты>` - Телепорт
- `/kit <название>` - Получить кит
- `/shop` - Открыть магазин
- `/balance` - Проверить баланс
- `/money <give/take/set> <игрок> <сумма>` - Управление деньгами (только админы)
- `/warn <игрок> <причина>` - Выдать предупреждение (только модераторы)
- `/inventory <игрок>` - Просмотр инвентаря игрока (только админы)
- `/restart <секунды>` - Перезагрузка сервера (только админы)
- `/saveall` - Сохранить все данные (только админы)


## Киты по умолчанию

Плагин создает следующие киты:
- **Старт** - Стартовый набор для новичков
- **VIP** - VIP набор с оружием и броней (требует права `rustadminpro.vip`)
- **Админ** - Админский набор (требует права `rustadminpro.admin`)
- **ПВП** - Набор для PvP сражений

## Магазин

В магазине доступны различные категории товаров:
- Оружие
- Броня
- Боеприпасы
- Ресурсы
- Медицина
- Взрывчатые вещества

Игроки получают стартовый баланс 1000 RP при первом подключении.
