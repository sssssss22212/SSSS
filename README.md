## 📦 Установка

### Автоматическая установка (рекомендуется)

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd casino-military-system

# Запустите автоматическую установку
python3 setup.py
```

### Ручная установка

1. **Установите зависимости Python:**
```bash
pip install -r requirements.txt
```

2. **Настройте веб-сервер** (Apache/Nginx) для файла `casino.php`

3. **Создайте базу данных MySQL** для казино:
```sql
CREATE DATABASE casino_db;
```

4. **Настройте Discord ботов:**
   - Создайте приложения в [Discord Developer Portal](https://discord.com/developers/applications)
   - Получите токены ботов
   - Добавьте токены в `.env` файл

## ⚙️ Конфигурация

Отредактируйте файл `.env`:

```env
# Discord Bot Tokens
CASINO_BOT_TOKEN=ваш_токен_казино_бота
MILITARY_BOT_TOKEN=ваш_токен_военного_бота

# Database Configuration
DB_HOST=localhost
DB_NAME=casino_db
DB_USER=root
DB_PASSWORD=ваш_пароль

# Casino Website Configuration
WEBSITE_URL=http://localhost/casino.php
ADMIN_PASSWORD=admin123
```

## 🐛 Поиск проблем

### Общие проблемы:

1. **Бот не отвечает:**
   - Проверьте токен в `.env`
   - Убедитесь, что бот добавлен на сервер
   - Проверьте права бота

2. **Ошибки базы данных:**
   - Запустите `python3 setup.py` повторно
   - Проверьте права доступа к файлам

3. **Сайт не работает:**
   - Проверьте настройки веб-сервера
   - Убедитесь, что MySQL база создана
   - Проверьте права на файлы PHP
