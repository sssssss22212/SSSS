# SCP-096 Mask Plugin

Плагин для SCP: Secret Laboratory, который позволяет игрокам надевать маски на SCP-096, делая его неагрессивным.

## Особенности

- 🎭 **Визуально отличимые маски**: Маски SCP-096 имеют увеличенный размер, красный цвет и эффект свечения
- 🌟 **Визуальные эффекты**: Маски вращаются и левитируют для лучшей заметности
- 🎯 **Настраиваемый спавн**: Гибкие настройки спавна по зонам или конкретным комнатам с шансами
- ⚡ **Два способа активации**: Server Specific Settings или NoClip
- 📊 **Подробная конфигурация**: Множество настроек для кастомизации игрового процесса
- 🛠️ **Админ команды**: Полный набор команд для управления масками

## Установка

1. Поместите `Scp096Mask.dll` в папку `%APPDATA%/EXILED/Plugins/`
2. Перезапустите сервер
3. Настройте конфиг в `%APPDATA%/EXILED/Configs/{server-port}-config.yml`

## Зависимости

- EXILED 9.6.1+
- HintServiceMeow 1.4.1+

## Использование

### Для игроков

1. Найдите маску SCP-096 (красная светящаяся аптечка)
2. Подберите маску
3. Подойдите к SCP-096 на расстояние взаимодействия
4. Нажмите назначенную клавишу или используйте NoClip (в зависимости от настроек)
5. Дождитесь завершения процесса одевания маски

### Для администраторов

Команды (требуют право `mask096.admin`):

- `mask096 spawn` - заспавнить маски
- `mask096 info` - информация о масках  
- `mask096 give <userid>` - выдать маску в инвентарь
- `mask096 create <userid>` - создать маску рядом с игроком
- `mask096 remove <userid>` - снять маску с SCP-096
- `mask096 list` - список замаскированных SCP-096
- `mask096 clear` - очистить все маски

## Конфигурация

### Основные настройки

```yaml
scp096_mask:
  is_enabled: true
  debug: false
  auto_spawn_enabled: true
  masks_to_spawn: 3
  mask_equip_time: 5.0
  interaction_distance: 3.0
  require_mask_in_hand: true
  activation_type: ServerSpecificSettings
```

### Настройки спавна

```yaml
  # Шансы спавна по зонам (0-100%)
  spawn_weights:
    LightContainment: 35.0
    HeavyContainment: 25.0
    Entrance: 20.0
    Office: 15.0
    Surface: 5.0
  
  # Использовать конкретные комнаты
  use_specific_rooms: false
  specific_spawn_rooms:
  - LczClassDSpawn
  - LczCheckpointA
  - Hcz049
```

### Внешний вид масок

```yaml
  mask_display:
    scale: 1.2
    color: '#FF6B6B'
    glow_effect: true
    glow_intensity: 2.0
    rotate: true
    rotation_speed: 30.0
    hover_height: 0.5
    hover_speed: 1.0
```

### Сообщения

```yaml
  messages:
    mask_picked_up: '<color=green>Вы подобрали маску SCP-096!</color>'
    no_mask: '<color=red>У вас нет маски SCP-096!</color>'
    too_far_away: '<color=red>Нет SCP-096 поблизости!</color>'
    mask_equipped: '<color=green>Маска успешно надета!</color>'
```

## Механика

1. **Подбор маски**: Игроки могут подбирать только специальные маски SCP-096
2. **Процесс одевания**: Занимает настраиваемое время с отображением прогресса
3. **Эффект маски**: SCP-096 с маской не может агриться и не видит игроков
4. **Ограничения**: Один игрок может иметь только одну маску
