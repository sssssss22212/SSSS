# PlayerManagerPlugin для Exiled

## Описание

PlayerManagerPlugin - это мощный плагин для SCP: Secret Laboratory, созданный на основе фреймворка Exiled. Плагин предоставляет расширенные возможности управления игроками и улучшает игровой опыт.

## Основные функции

### 🎯 Система очков
- Автоматическое начисление очков за убийства
- Различные награды за убийство SCP и обычных игроков  
- Отображение топа игроков в конце раунда
- Команды для просмотра очков

### 👋 Приветствие игроков
- Настраиваемое приветственное сообщение
- Автоматический показ при подключении
- Настройка длительности показа

### 💊 Автолечение
- Автоматическое восстановление здоровья при спавне
- Настраиваемое количество ХП

### 🎒 Стартовые предметы
- Выдача дополнительных предметов определенным ролям
- Полная настройка через конфигурацию

### 🚫 AFK система
- Автоматический кик неактивных игроков
- Предупреждения перед киком
- Настраиваемое время ожидания

### 💬 Сообщения о смерти
- Уведомления о убийствах
- Настраиваемый формат сообщений

### ⚡ Админ команды
- Лечение игроков
- Телепортация
- Выдача предметов
- Получение информации об игроках
- Кик и убийство игроков

## Установка

### 1. Требования
- SCP: Secret Laboratory сервер
- Exiled Framework версии 8.0.0 или выше
- .NET Framework 4.8

### 2. Загрузка зависимостей
Скачайте компоненты Exiled по ссылке: https://drive.google.com/drive/folders/1KKgCaKOlj_wGlNlUGO37KJCNkbR9DGCm

### 3. Компиляция плагина
```bash
# Установите переменную среды EXILED_REFERENCES
export EXILED_REFERENCES=/path/to/exiled/references

# Компилируйте проект
dotnet build --configuration Release
```

### 4. Установка плагина
1. Скопируйте файл `PlayerManagerPlugin.dll` из папки `bin/Release` в папку `%AppData%/EXILED/Plugins` (Windows) или `~/.config/EXILED/Plugins` (Linux)
2. Перезапустите сервер

## Конфигурация

Конфигурационный файл создается автоматически при первом запуске плагина в папке `%AppData%/EXILED/Configs` или `~/.config/EXILED/Configs`.

### Основные настройки

```yaml
player_manager_plugin:
  # Включен ли плагин
  is_enabled: true
  
  # Отладочный режим
  debug: false
  
  # Приветственное сообщение
  welcome_message: "<color=green>Добро пожаловать на сервер!</color>"
  welcome_message_duration: 5
  
  # Автолечение
  auto_heal_on_spawn: true
  auto_heal_amount: 100
  
  # Система очков
  enable_point_system: true
  points_for_scp_kill: 100
  points_for_player_kill: 50
  points_for_escape: 200
  
  # Сообщения о смерти
  show_death_message: true
  death_message_format: "<color=red>{player} был убит игроком {killer} ({reason})</color>"
  
  # AFK система
  enable_afk_kick: true
  afk_kick_time: 300
  afk_kick_message: "Вы были кикнуты за неактивность"
  
  # Стартовые предметы для ролей
  role_starting_items:
    Scientist: 
      - KeycardScientist
      - Flashlight
    ClassD:
      - Coin
    Guard:
      - KeycardGuard
      - Radio
  
  # Ограничения ролей
  max_players_per_role:
    Scp173: 1
    Scp106: 1
    Scp096: 1
    Scp049: 1
```

## Команды

### Просмотр очков
```
points [игрок] - Показать очки игрока или всех игроков
Алиасы: pts, очки
Разрешение: pm.points
```

### Управление игроками
```
pm heal <игрок> [хп] - Лечит игрока
pm tp <игрок1> <игрок2> - Телепортирует игрока1 к игроку2  
pm item <игрок> <предмет> [количество] - Выдает предмет игроку
pm info <игрок> - Показывает информацию об игроке
pm kick <игрок> [причина] - Кикает игрока
pm kill <игрок> - Убивает игрока

Алиасы: playermanager, пм
```

### Разрешения
- `pm.points` - Просмотр очков игроков
- `pm.heal` - Лечение игроков
- `pm.teleport` - Телепортация игроков
- `pm.item` - Выдача предметов
- `pm.info` - Просмотр информации об игроках
- `pm.kick` - Кик игроков
- `pm.kill` - Убийство игроков
