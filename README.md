# 🤖 Minecraft AI Bot v2.0

Продвинутый ИИ-бот для Minecraft 1.21.8 с машинным обучением, автоматической добычей ресурсов, строительством и боевой системой.

## 🌟 Особенности

### 🧠 Искусственный интеллект
- **Машинное обучение** с Q-learning алгоритмом
- **Адаптивное поведение** на основе опыта
- **Автоматическое принятие решений**
- **Анализ паттернов** и оптимизация стратегий

### ⚔️ Боевая система
- **Умная боевая тактика** (кайтинг, hit-and-run, прямой бой)
- **Анализ угроз** и выбор стратегии
- **Автоматическое экипирование** лучшего оружия
- **Избегание опасностей** и бегство при необходимости

### 🏗️ Строительство
- **Автоматическое строительство** домов, башен, мостов
- **Шаблоны построек** с настраиваемыми параметрами
- **Планирование строительства** с проверкой материалов
- **Умное размещение блоков** и оптимизация

### ⛏️ Добыча ресурсов
- **Автоматическая добыча** всех типов руд и блоков
- **Умный выбор инструментов** для каждого блока
- **Приоритизация ценных ресурсов**
- **Оптимизация маршрутов** добычи

### 💬 Голосовое управление
- **Команды через чат** на русском языке
- **Макро-команды** для сложных действий
- **Гибкая система команд** с параметрами
- **Обратная связь** и статистика

### 🎯 Навигация и движение
- **A* алгоритм** для поиска пути
- **Избегание препятствий**
- **Умное перемещение** с учетом местности
- **Следование за игроками**

## 📋 Требования

### Системные требования
- **Python 3.8+**
- **Node.js 14+** (для mineflayer)
- **4GB RAM** (рекомендуется 8GB)
- **Интернет соединение**

### Поддерживаемые платформы
- ✅ **Linux** (Ubuntu, Debian, CentOS)
- ✅ **Windows** 10/11
- ✅ **macOS** 10.15+
- ✅ **Android** (через Termux + proot Ubuntu)

## 🚀 Установка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd minecraft-ai-bot
```

### 2. Установка зависимостей
```bash
# Установка Python зависимостей
pip install -r requirements.txt

# Установка Node.js зависимостей (если нужно)
npm install mineflayer mineflayer-pathfinder
```

### 3. Для Android (Termux)
```bash
# Установка в Termux
pkg update && pkg upgrade
pkg install python nodejs git
pip install -r requirements.txt
```

## 💬 Команды бота

### Основные команды
- `помощь` - показать список команд
- `статус` - показать текущий статус бота
- `стоп` - остановить все задачи

### Движение
- `иди x y z` - перейти к координатам
- `следуй` - следовать за игроком

### Добыча и ресурсы
- `копай [блок]` - добыча блоков
- `добывай камень` - добыча определенного ресурса
- `добывай железо` - добыча железной руды
- `добывай алмаз` - добыча алмазов

### Строительство
- `строй дом` - построить дом
- `строй башня` - построить башню
- `строй мост` - построить мост
- `дом` - быстрая команда для дома

### Крафт и экипировка
- `крафт [предмет]` - скрафтить предмет
- `одевайся` - экипировать лучшие предметы
- `ешь` - поесть еду

### Боевые команды
- `атака` - атаковать ближайшего моба
- `дроп` - сбросить все предметы

### Расширенные команды
- `макро [название]` - выполнить макро-команду
- `анализ` - показать анализ поведения
- `локации` - показать известные локации
- `оптимизация` - оптимизировать инвентарь
- `стратегия [тип]` - изменить стратегию поведения

## 🎯 Макро-команды

### Готовые макросы
- `макро prepare_night` - подготовка к ночи
- `макро mining_session` - сессия добычи
- `макро build_base` - строительство базы

### Стратегии поведения
- **Агрессивная** - больше исследований и рисков
- **Осторожная** - безопасное поведение
- **Сбалансированная** - оптимальный баланс

## 🧠 Машинное обучение

Бот использует Q-learning алгоритм для обучения:

- **Состояния**: здоровье, голод, время, окружение
- **Действия**: движение, добыча, строительство, бой
- **Награды**: за выживание, успешные действия
- **Штрафы**: за получение урона, смерть

### Данные обучения
Бот сохраняет данные в файлы:
- `bot_learning_data.pkl` - Q-таблица и статистика
- `minecraft_bot.log` - логи работы

## 🐛 Решение проблем

### Ошибки подключения
1. Проверьте адрес и порт сервера
2. Убедитесь что сервер онлайн
3. Проверьте версию Minecraft

### Ошибки зависимостей
```bash
# Переустановка зависимостей
pip uninstall mineflayer javascript
pip install -r requirements.txt
```

### Проблемы с Node.js
```bash
# Установка Node.js модулей глобально
npm install -g mineflayer mineflayer-pathfinder
```

## 📱 Запуск на Android

### Через Termux
1. Установите Termux из F-Droid
2. Установите proot-distro:
```bash
pkg install proot-distro
proot-distro install ubuntu
proot-distro login ubuntu
```

3. В Ubuntu установите зависимости:
```bash
apt update && apt install python3 python3-pip nodejs npm git
pip3 install -r requirements.txt
```

4. Запустите бота:
```bash
python3 run_bot.py
```
