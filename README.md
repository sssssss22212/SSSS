## 🎯 Ключевые особенности

### Визуальное отличие масок
- **Размер**: 1.2x от обычных аптечек
- **Свечение**: Красноватое свечение (настраивается)
- **Анимация**: Вращение и подпрыгивание
- **Все эффекты настраиваются в конфиге**

### Умный спавн масок
- Приоритетные комнаты с настраиваемыми шансами
- Спавн по зонам с весами
- Минимальное расстояние между масками
- Проверка коллизий и запрещенные зоны

### Harmony патчи
- Предотвращение агрессии SCP-096 в маске
- Блокировка обнаружения игроков
- Предотвращение ярости
- Дополнительные патчи для полной функциональности

## 📋 Команды

### Команды для всех игроков
- `mask096 help` - показать справку по командам
- `mask096 use` - использовать маску (если есть в инвентаре)
- `usemask` / `mask` / `umask` - быстрая команда использования маски

### Команды администратора (Требуется: `mask096.admin`)
- `mask096 spawn [количество]` - заспавнить маски
- `mask096 info` - основная информация
- `mask096 stats` - подробная статистика
- `mask096 clear` - удалить все маски
- `mask096 reload` - перезагрузить конфигурацию
- `mask096 debug [on/off]` - переключить режим отладки

### Работа с игроками (админ)
- `mask096 give <userid> [x] [y] [z]` - создать маску в позиции
- `mask096 giveinv <userid>` - выдать маску в инвентарь
- `mask096 remove <userid>` - снять маску с SCP-096
- `mask096 list` - список замаскированных SCP-096

### Информационные команды
- `maskinfo` - подробная информация (Требуется: `mask096.info` или `mask096.admin`)

## ⚙️ Конфигурация

### Настройки спавна
```yaml
MasksToSpawn: 5
AutoSpawnEnabled: true
MinMaskDistance: 15.0
MaxSpawnAttempts: 20

# Шансы спавна по зонам (%)
SpawnWeights:
  LightContainment: 40.0
  HeavyContainment: 30.0
  Entrance: 20.0
  Surface: 5.0
  Other: 5.0

# Конкретные комнаты с высоким приоритетом
SpecificRoomSpawn:
  Hcz096: 80.0          # Камера SCP-096
  Lcz914: 60.0          # SCP-914
  LczClassDSpawn: 40.0  # Спавн класса D
```

### Визуальные эффекты
```yaml
VisualSettings:
  Scale: 1.2              # Размер маски
  EnableGlow: true        # Свечение
  GlowColor: "255,150,150" # Цвет свечения
  EnableRotation: true    # Вращение
  RotationSpeed: 30.0     # Скорость вращения
  EnableBobbing: true     # Подпрыгивание
  BobbingHeight: 0.3      # Высота подпрыгивания
```

### Продвинутые настройки
```yaml
AdvancedSpawn:
  OnlyWhenScp096Present: true    # Спавн только при наличии SCP-096
  MinPlayersForSpawn: 5          # Минимум игроков для спавна
  MaxMasksOnMap: 8               # Максимум масок на карте
  EnableRespawn: false           # Респавн масок в течение раунда
  LogMaskSpawns: true            # Логирование спавна масок
```

## 🔗 Активация

### Серверные настройки (рекомендуется)
Игроки получают клавишу в настройках сервера для взаимодействия с масками.

### NoClip (альтернатива)
Игроки с маской могут использовать NoClip рядом с SCP-096 для одевания маски.

## 🛠️ Установка

1. Поместите все файлы в папку плагинов
2. Настройте конфигурацию в `Config.cs`
3. Выдайте права администраторам:
   - `mask096.admin` - основные команды
   - `mask096.info` - команда информации
4. Перезапустите сервер

## 🐛 Отладка

Включите режим отладки в конфиге:
```yaml
Debug: true
```

Это покажет подробную информацию о:
- Спавне масок и их позициях
- Процессе одевания масок
- Работе патчей Harmony
- Ошибках и предупреждениях

## 📝 Логи

При включенном `LogMaskSpawns: true` в логах будет отображаться:
- Позиция каждой заспавненной маски
- Комната, где заспавнилась маска
- Информация о респавне масок
