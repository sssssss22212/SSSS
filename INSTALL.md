# 🚀 Установка плагина SCP-035

## 📋 Требования

- **SCP Secret Laboratory** версии 13.4.0 или выше
- **Exiled Framework** версии 8.0.0 или выше  
- **HintServiceMeow** плагин (любая версия)

## 🔧 Пошаговая установка

### 1. Установка Exiled
1. Скачайте последнюю версию [Exiled](https://github.com/Exiled-Team/EXILED/releases)
2. Распакуйте в папку с сервером
3. Запустите `Exiled.Installer.exe`

### 2. Установка HintServiceMeow
1. Скачайте [HintServiceMeow](https://github.com/MeowServer/HintServiceMeow/releases)
2. Поместите `HintServiceMeow.dll` в папку `plugins`

### 3. Установка SCP-035 плагина
1. Скомпилируйте проект или скачайте готовую DLL
2. Поместите `SCP035Plugin.dll` в папку `plugins`
3. Перезапустите сервер

## 📁 Структура папок

```
SCP Secret Laboratory/
├── SCPSL_Data/
├── Exiled/
│   ├── Plugins/
│   │   ├── SCP035Plugin.dll          ← Основной плагин
│   │   ├── HintServiceMeow.dll       ← Система подсказок
│   │   └── dependencies/
│   └── Configs/
│       └── 7777-config.yml           ← Конфигурация сервера
└── LocalAdmin.exe
```

## ⚙️ Первоначальная настройка

После первого запуска в конфигурации появится секция:

```yaml
scp035_plugin:
  is_enabled: true
  debug: false
  enable_s_c_p035_spawn: true
  min_players_for_spawn: 5
  s_c_p035_spawn_chance: 15
  # ... остальные настройки
```

## 🔑 Права доступа

Добавьте в конфигурацию Exiled:

```yaml
permissions:
  default:
    - scp035.admin  # Для администраторов
```

## ✅ Проверка работы

1. Запустите сервер
2. Проверьте логи на наличие сообщения: `✅ SCP-035 Одержимая Маска v1.0.0 загружен`
3. Используйте команду `scp035 info` в консоли

## 🐛 Устранение проблем

### Плагин не загружается
- Проверьте версию Exiled
- Убедитесь, что HintServiceMeow установлен
- Проверьте логи сервера

### Ошибки компиляции
- Убедитесь, что установлен .NET Framework 4.8
- Проверьте пути к зависимостям Exiled

### Подсказки не работают
- Проверьте установку HintServiceMeow
- Убедитесь в правильности конфигурации HSM

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи сервера
2. Убедитесь в правильности установки зависимостей
3. Обратитесь за помощью с полной информацией об ошибке
